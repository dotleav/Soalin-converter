Soalin — Konverter Docx (di HP/tablet, tanpa terminal)

Halaman ini menjalankan konversi docx → questions.js + gambar langsung di browser kamu (tidak ada file yang dikirim ke server manapun). Hasilnya bisa diunduh sebagai satu file .patch yang tinggal di-git am / git apply ke repo Soalin (gambar ikut, sebagai binary patch).

1 Pilih file .docx

Kosongkan keduanya kalau mau mode lama (langsung ke data/questions.js). Isi Kategori kalau mau soal ini jadi "paket" terpisah yang bisa dipilih di app (sama seperti npm run convert -- file.docx "Kategori" "Nama Paket").

2 Batch saat ini

Bisa ulangi Langkah 1 untuk konversi beberapa file docx sekaligus sebelum diunduh — semuanya akan digabung jadi satu .patch.

3 Repo tujuan

Patch dibuat sebagai diff terhadap data/manifest.js (dan questions.js kalau sudah ada) di repo ini — diambil otomatis dari GitHub saat unduh, jadi patch cocok dengan isi repo yang sekarang.
Offline / repo private? Tempel manifest lama manual
Kalau diisi, dipakai menggantikan hasil fetch. Harus persis sama dengan data/manifest.js di repo, kalau tidak patch akan gagal diterapkan.

4 Unduh

Menghasilkan soalin-hasil-konversi.patch (data/, images/, dan update data/manifest.js). Upload ke root repo di Codespaces, lalu jalankan:
git am soalin-hasil-konversi.patch
atau tanpa bikin commit: git apply --index soalin-hasil-konversi.patch. Lalu git push.
Re-convert paket yang sudah ada? Hapus dulu: git rm -r data/packages/<id> images/packages/<id> dan commit, baru apply.
Kenapa bukan file APK?

Bikin APK butuh Android Studio / Gradle buat compile — itu sendiri butuh "terminal" (walau bukan di tablet kamu). Halaman ini adalah jalan pintasnya: tidak perlu install apa-apa, cukup buka di Chrome/browser tablet kamu (bisa juga di-"Add to Home screen" biar kelihatan kayak app). Kamu bisa host file ini di GitHub Pages repo Soalin kamu sendiri (taruh sebagai converter.html) supaya gampang dibuka kapan saja dari HP.
