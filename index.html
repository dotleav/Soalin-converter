Soalin — Konverter Docx (di HP/tablet, tanpa terminal)

Halaman ini menjalankan konversi docx → questions.js + gambar langsung di browser kamu (tidak ada file yang dikirim ke server manapun). Hasilnya bisa diunduh sebagai satu file .tar.gz yang siap ditaruh di repo lewat GitHub Codespaces.

1 Pilih file .docx

Kosongkan keduanya kalau mau mode lama (langsung ke data/questions.js). Isi Kategori kalau mau soal ini jadi "paket" terpisah yang bisa dipilih di app (sama seperti npm run convert -- file.docx "Kategori" "Nama Paket").

2 Batch saat ini

Bisa ulangi Langkah 1 untuk konversi beberapa file docx sekaligus sebelum diunduh — semuanya akan digabung jadi satu .tar.gz.

3 (Opsional) Gabung dengan manifest lama

Kalau repo kamu sudah punya paket lain di data/manifest.js, tempel isinya di sini supaya paket baru ditambahkan, bukan menimpa daftar lama.

4 Unduh

Menghasilkan soalin-hasil-konversi.tar.gz berisi data/ dan images/ sesuai struktur folder Soalin. Push ke repo via Codespaces lalu jalankan:
tar -xzf soalin-hasil-konversi.tar.gz
di root repo (isinya akan menimpa/menambah file yang sama).
Kenapa bukan file APK?

Bikin APK butuh Android Studio / Gradle buat compile — itu sendiri butuh "terminal" (walau bukan di tablet kamu). Halaman ini adalah jalan pintasnya: tidak perlu install apa-apa, cukup buka di Chrome/browser tablet kamu (bisa juga di-"Add to Home screen" biar kelihatan kayak app). Kamu bisa host file ini di GitHub Pages repo Soalin kamu sendiri (taruh sebagai converter.html) supaya gampang dibuka kapan saja dari HP.
